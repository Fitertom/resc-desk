# resc-desk

Wayland-композитор и рабочий стол на Rust, написанные с нуля. Поведение как в Windows 11.
Сторонних крейтов нет, только `std`. Всё, что ниже `std`, лежит здесь.

## Структура

| Крейт / модуль | Что делает |
|---|---|
| `crates/sys` | Сисколлы, которых нет в std: передача fd (SCM_RIGHTS), epoll, mmap, memfd, timerfd, flock, защита от SIGBUS для shm |
| `crates/wl/build.rs` | Свой сканер Wayland: XML-парсер и кодогенерация типизированных Request/Event и send-функций для обеих сторон |
| `crates/wl/src/wire.rs` | Wire-протокол: фрейминг, аргументы, очередь fd, лимит 28 fd на sendmsg |
| `desk/server.rs` | Диспетчер всех запросов: wl_compositor/surface/region/shm/subsurface, seat, data device (буфер обмена), xdg-shell (toplevel, popup, positioner с flip/slide), xdg-decoration, viewporter, fractional-scale, xdg-output, cursor-shape, single-pixel-buffer |
| `desk/wm.rs` | Оконный менеджер: каскадное размещение, фокус и поднятие по клику, развёртывание, Aero Snap (половины и четверти), сворачивание, показ рабочего стола, перенос между мониторами, виртуальные столы, enter/leave на выходах, предпочтительный масштаб |
| `desk/input.rs` | Маршрутизация указателя и клавиатуры, неявные захваты, перемещение и ресайз, превью снапа, горячие клавиши |
| `desk/render.rs` | CPU-композитор: сцена на каждый выход, перерисовка только повреждённых областей, отсечение под непрозрачными окнами, буферы клиентов читаются без копирования. Стекло: размытие того, что под панелью (уменьшение, box blur ×2, билинейное увеличение), повреждение вокруг стекла расширяется на радиус размытия |
| `desk/glass.rs` | Стекло Liquify построчно: стеклянная карточка из `ui.frag` (преломление на крае, матовость с насыщенностью 1.6, тонировка, внутренняя тень, блик, подсветка, рамка), тень из `glass.frag`, скругления из `squircle.glsl`. Параметры как у Liquify на рабочем столе: толщина 30, край 36 (меняется в настройках), размытие σ 70, тонировка rgba(18,18,22,0.55). Это путь на процессоре |
| `shaders/liquify/` | Исходники шейдеров Liquify без изменений. GPU-рендер берёт из них `ui.frag` (вид 2, стеклянная карточка), `ui.vert`, `glass.vert` и `fullscreen.vert` |
| `shaders/resc/`, `shaders/spv/` | Свои шейдеры: `layer.frag` накладывает слой, нарисованный CPU; `shadow.frag` — тень из `glass.frag` без изменений; `blur.frag` — один проход раздельного гаусса для матового стекла; `drop.vert`/`drop.frag` — капля жидкого стекла для анимаций окон (гладкое объединение SDF с каплей наведения на панели, стекло из `ui.frag`, тень, ободок); `surface.frag` обрезает углы окна, верхние и нижние своим радиусом. Готовый SPIR-V лежит в репозитории, для сборки компилятор шейдеров не нужен; после правки шейдеров запусти `shaders/build.sh` (glslangValidator) |
| `desk/gpu/vk.rs` | Своя обвязка Vulkan 1.3 (и 1.2 с `VK_KHR_dynamic_rendering`, как у dzn в WSL2): структуры, константы и функции, которые нужны рендеру. Библиотека грузится через `dlopen("libvulkan.so.1")`, без крейтов |
| `desk/gpu/mod.rs` | GPU-рендер (RADV на AMD, ANV на Intel). Окна клиентов, их рамки и обои — текстуры GPU, которые обновляются только там, где что-то поменялось. CPU рисует два слоя: содержимое панели, оверлеи и курсор. GPU собирает кадр и рисует стекло между слоями шейдерами Liquify: копия того, что под панелью, уменьшается mip-цепочкой до уровня с текселем примерно σ/4, по нему идут два прохода гаусса (`blur.frag`, по горизонтали и по вертикали, без копий-призраков и квадратов), затем `ui.frag` Liquify читает готовое размытие, рисует тень и карточку. Стекло процессор больше не считает |
| `desk/shell.rs` | Оформление в стиле Liquify: стеклянная панель задач двумя островками (по центру «Пуск», «Представление задач» и окна, справа раскладка, сеть, звук и часы) с пружинной анимацией акцентной «капли», превью окна при наведении на его кнопку (живая миниатюра, заголовок, крестик), Alt+Tab с живыми миниатюрами. Рамка окон: скругление 10 px (развёрнутые и прижатые окна прямоугольные, как в Windows 11), светлый ободок сверху, кнопки заголовка со скруглённой подсветкой, мягкая тень по скруглённой форме. Содержимое окна обрезается по тем же углам: на GPU в `surface.frag`, на CPU смешиванием угловых пикселей |
| `desk/winanim.rs` | Анимации окон каплей жидкого стекла (на GPU): открытие и восстановление из кнопки на панели, сворачивание в неё, всплытие и скрытие превью, разворачивание превью в окно по клику. У каждого параметра (края, радиус, иконка, вставки содержимого, заголовок, кнопки) своя кривая Безье со своим окном времени; перешеек к капле наведения — `smin` с k = 50·4p(1−p); разворот на полпути продолжает с текущего вида. Содержимое растягивается вместе с каплей без перерисовки клиента. `ctl slowmo` замедляет для записи. На CPU-пути окна просто появляются и исчезают |
| `desk/startanim.rs` | Анимация «Пуска» (на GPU): стекло меню растекается из кнопки с перешейком к капле наведения; четыре квадрата логотипа летят по боковым дугам — верхние сливаются в поиск, нижний левый становится аватаром, нижний правый делится на шестерёнку и питание. Содержимое лежит в стекле под каплями и проявляется волной снизу от середины; текст поиска открывается по перекрытию капель. Закрытие и разворот на полпути — с текущего вида |
| `desk/boot.rs` | Анимация загрузки (Gravity Burst): с первого кадра — чёрный экран и шар из 2000 частиц со следами; когда загрузка завершилась (обои декодированы, окна `--spawn` показались), шар взрывается, и рабочий стол открывается многоугольником за частицами. `RESC_BOOT=0` — без неё, `ctl boot` — повторить, клик — взорвать сразу |
| `desk/life.rs` | Запуск и закрытие программ (на GPU). Кнопки на панели вырастают и лопаются, соседи раздвигаются и смыкаются. Пока программа грузится, под иконкой дышит капля: под кнопкой на панели (О1) или под значком в «Пуске», по которому кликнули (О2), и окно вырастает оттуда. Закрытое окно уходит со своим последним кадром (текстуры остаются на GPU): втягивается в кнопку, которая лопается (З1), испаряется каплей (З2) или втягивается в ✕ (З3). Выбор в «Параметрах» → «Оформление» или `ctl anim launch 0|1`, `ctl anim close 0|1|2`. Программы с dma-buf (браузеры и игры на железе) пока уходят без последнего кадра |
| `desk/alttab.rs` | Alt+Tab каплями (на GPU). Панель вырастает из капли в центре, у неё только стеклянная кайма, без подложки. Карточки приходят волной от выбранной, картинка окна оседает в миниатюру. Под выбранной карточкой перетекает капля: передний край первым, задний догоняет. Когда отпускаешь Alt, карточка разворачивается в окно, остальное быстро уходит; Esc проигрывает появление назад. Быстрый Alt+Tab без анимации карточек. На CPU-пути прежняя неподвижная панель |
| `desk/taskview.rs` | «Представление задач» (Win+Tab, кнопка на панели): матовое стекло на весь экран, живые карточки окон рабочего стола, полоса рабочих столов с миниатюрами (обои и окна в миниатюре), «Создать»; перетаскивание карточки на стол переносит окно, × закрывает окно или стол |
| `desk/tray.rs` | Правый островок и его всплывающие панели: сеть (Wi-Fi вкл/выкл, список сетей с уровнем сигнала, подключение с паролем, отключение, «Параметры сети» открывают nmtui), звук (громкость выхода и микрофона, выключение, выбор устройства; колесо над значком и клавиши громкости), календарь (месяц с листанием, сегодня акцентом) |
| `desk/pulse.rs` | Свой клиент нативного протокола PulseAudio (без libpulse): работает с PulseAudio, pipewire-pulse и сервером WSLg. Устройства вывода и ввода, громкость, выключение, устройство по умолчанию, подписка на изменения. Проверка из консоли: `resc-desk sound [volume N\|mute\|unmute]` |
| `desk/dbus.rs`, `net.rs` | Свой клиент D-Bus (системная шина, SASL EXTERNAL, сериализация всех типов) и NetworkManager поверх него: устройства, точки доступа, сохранённые профили, подключение WPA/WPA3-Personal и открытых сетей. Проверка: `resc-desk net` |
| `desk/start.rs` | «Пуск» как в демо: поиск, «Закреплённые» (правый клик закрепляет и открепляет), «Недавние», страница «Все приложения» с прокруткой, стрелки ходят по ближайшему элементу, внизу пользователь, «Параметры» и меню питания (выход, перезагрузка, выключение). Закреплённые и недавние хранятся в `~/.config/resc-desk/start.conf` |
| `desk/icons.rs` | Иконки приложений: окно → .desktop (id, `StartupWMClass`, имя из `Exec`) → имя иконки → файл в темах freedesktop (Papirus, Breeze, Adwaita, hicolor, `RESC_ICON_THEME` первой) или в `/usr/share/pixmaps`. PNG, SVG и XPM, кэш растров на каждый размер |
| `desk/svg.rs` | Свой SVG для иконок: XML, пути со всеми командами (дуги тоже), фигуры, `g`/`use`/`symbol`, трансформации, линейные и радиальные градиенты, обводки, nonzero/evenodd, прозрачность, `currentColor` и простые классы из `<style>`. Растеризация со сглаживанием (5 подстрок на пиксель, точное покрытие по горизонтали). Без клип-путей, масок и фильтров |
| `desk/font.rs` | Свой TrueType: cmap 4/12, glyf (составные глифы), растеризатор по площади покрытия, кэш глифов. Manrope 500/600/800 встроен в бинарник (`assets/fonts`, OFL), системный шрифт идёт запасным для остальных письменностей |
| `desk/backend/nested.rs` | Работа внутри другого композитора (WSLg, KDE, GNOME): одно окно хоста на монитор |
| `desk/backend/headless.rs` | Выходы в памяти: тесты и CI |

## Запуск (Arch в WSL)

```sh
pacman -S --needed rust foot weston ttf-dejavu xkeyboard-config
cargo build --release
# два «монитора» = два окна на рабочем столе Windows; их можно разнести по реальным мониторам
./target/release/resc-desk --outputs 1920x1080,1280x1024@1.25 --spawn foot
# из другого терминала
./target/release/resc-desk ctl windows
./target/release/resc-desk ctl screenshot /tmp/s.png
```

### На настоящем Linux (без другого композитора)

Перейти на текстовую консоль (Ctrl+Alt+F3), войти и запустить `resc-desk`. Без `WAYLAND_DISPLAY` он сам берёт KMS; явно — `--backend kms`, другую карту — `RESC_DRM_DEVICE=/dev/dri/card1`. Нужен доступ к `/dev/dri/card*` и `/dev/input/event*`. Видеокарту пользователю на консоли открывает logind (правило `uaccess`), а клавиатуры и мыши — нет (оно отдаёт только джойстики), поэтому нужна группа `input`: `sudo usermod -aG input,video $USER`, потом перелогиниться. Выход — Win+Shift+Backspace.

#### Первый запуск на ноутбуке

KMS-путь на железе ещё не запускался, поэтому первый раз — осторожно:

1. Пакеты (Intel): `mesa vulkan-intel intel-media-driver xorg-xwayland foot papirus-icon-theme ttf-dejavu rustup git`; для AMD вместо `vulkan-intel` — `vulkan-radeon`. Запасной рабочий стол (`plasma` или `gnome`) тоже поставь: если что-то пойдёт не так, будет куда войти.
2. `rustup default stable`, затем в папке проекта `cargo build --release` (сторонних crate нет, интернет не нужен).
3. `sudo usermod -aG input,video $USER` и перелогиниться (проверка: `groups`).
4. Ctrl+Alt+F3, войти, запустить с журналом: `RESC_DEBUG=1 ./target/release/resc-desk 2> ~/resc.log`.
5. Если экран завис: Ctrl+Alt+F2 — другая консоль (переключение VT обрабатывает сам resc-desk), там `pkill resc-desk`. При выходе и падении консоль возвращается в текстовый режим.
6. Если не взлетел Vulkan — `RESC_RENDER=cpu`. Пришли `~/resc.log` и вывод `vulkaninfo --summary` (пакет `vulkan-tools`).

Сразу в рабочий стол при включении, без ввода логина и пароля (systemd): автовход на первой консоли и запуск оттуда.

```sh
sudo systemctl edit getty@tty1
# в открывшийся файл:
# [Service]
# ExecStart=
# ExecStart=-/sbin/agetty --autologin ИМЯ --noclear %I $TERM

# в конец ~/.bash_profile:
[ -z "$WAYLAND_DISPLAY" ] && [ "$(tty)" = /dev/tty1 ] && exec resc-desk
```

Сеанс при этом всё равно настоящий (logind его заводит сам): видеокарта доступна сразу, для клавиатуры и мыши нужна группа `input` (см. выше). После выхода или падения getty снова войдёт и запустит его; обычная текстовая консоль остаётся на Ctrl+Alt+F2.

Рендер выбирается переменной `RESC_RENDER`:
- не задана: Vulkan, если есть настоящий GPU с Vulkan 1.3 (или 1.2 с `VK_KHR_dynamic_rendering`), иначе CPU;
- `vulkan`: Vulkan на любом устройстве, включая программный lavapipe (для проверок);
- `cpu`: только процессор.

В WSL2 Vulkan идёт через dzn (Direct3D 12 на видеокарте Windows, Vulkan 1.2): `RESC_RENDER=vulkan` (dzn помечен как неполная реализация, поэтому сам он не выбирается). `/dev/dri` в WSL2 нет, поэтому dmabuf там не проверить: только на железе.

Иконки: любая тема freedesktop, для проверки хватит `pacman -S papirus-icon-theme`. Шейдеры после правки: `pacman -S glslang` и `shaders/build.sh`.

`RESC_VK_VALIDATE=1` включает слой проверки Khronos. Если Vulkan падает посреди работы, композитор сам переходит на CPU с полного кадра. В WSL1 нет `memfd_create`, без которого lavapipe не может отобразить память. Для проверок там подставляется маленькая заглушка через `LD_PRELOAD` (открывает удалённый файл в `/tmp`). На настоящем Linux она не нужна.

## Горячие клавиши

`Mod` — это Win. Во вложенном режиме Win перехватывает Windows, поэтому вместо него работает Ctrl+Alt.

|---|---|
| Win (одно нажатие), Mod+S | «Пуск» с поиском, сразу можно печатать |
| Win+V | Журнал буфера обмена: последние 25 текстов. Enter или клик вставляет запись в активное окно (в терминалы через Ctrl+Shift+V), Del удаляет её |
| Win+I | «Параметры» (уже открытое окно поднимается). Сохраняется в `~/.config/resc-desk/displays.conf` |
| Alt+Shift, Win+Space | Сменить раскладку EN/RU (индикатор в правом острове). Alt+Shift срабатывает при отпускании и только если между ними не нажималось ничего, поэтому Alt+Shift+стрелки раскладку не меняют |
| В полях оболочки | Стрелки, Home/End, Ctrl+стрелки (по словам), всё то же с Shift для выделения, Backspace/Delete (с Ctrl по словам), Ctrl+A/C/X/V, Ctrl+Z, Ctrl+Y и Ctrl+Shift+Z, Ctrl+Insert, Shift+Insert, Shift+Delete |

- заголовок окна можно перетаскивать к краю экрана для снапа;

- средний клик по заголовку сворачивает;
- клик по кнопке на панели переключает «свернуть / активировать».

## Физическая раскладка мониторов (`desk/layout.rs`)

Координаты рабочего стола устроены как физическая плоскость в миллиметрах: логическая точка = (мм − начало) × k. Одна логическая единица — один и тот же физический размер на любом мониторе. Масштаб каждого монитора выводится из его плотности пикселей. Отсюда:
- окно при переносе через стык не меняет ни высоту, ни размер;
- окно, стоящее на двух мониторах, идёт ровно через рамку, а кусок за рамкой не виден;
- курсор перескакивает зазор рамки на той же физической высоте, как в LittleBigMouse.

Откуда берётся плоскость, по приоритету:
1. `~/.config/resc-desk/displays.conf`;
2. импорт `Current.xml` из LittleBigMouse с той же правкой `square_planes`, что в RESC F11;
3. размер монитора из EDID;
4. 96 dpi.

**Калибровка: Win+P или «Пуск» → «Мониторы и линейки».**
- Экран показывает линейки по краям с шагом 1 мм, сетку 10/50/100 мм в общих координатах и контур банковской карты 85.6×54 мм.
- Tab — выбрать монитор. Стрелки — сдвинуть его на 0.5 мм (с Shift — на 5 мм), пока линии не сойдутся через рамку.
- +/− — подогнать размер по карте.
- G — «Склеить»: горизонтальные зазоры между мониторами убираются, и за рамкой ничего не пропадает. Высота и физический масштаб остаются как при калибровке.
- L — взять раскладку из LittleBigMouse.

**Обои (`desk/wallpaper.rs`)** — одна картинка на всю плоскость, а не на каждый монитор отдельно. В физическом режиме линия на обоях идёт ровно через стык, а в режиме «Склеить» обои идут без разрыва. Встроенные обои рисуются процедурно, свои загружаются как PNG (декодер и inflate свои). Каждый монитор держит готовую копию в своём разрешении.
- Enter — сохранить, Esc — отменить.

Эмуляция мониторов для тестов: `--outputs 3440x1440/1048x441,2560x1080/572x241,1080x1920/296x532`. Управление через `ctl`: `planes`, `set-plane NAME x y w h`, `import-lbm PATH`, `ui-scale V`, `calibrate`, `glue on|off`, `wallpaper PATH|default`.

## Дальше по плану

1. ~~Первый запуск в WSL~~: проверены foot, weston-terminal, GTK4 (gtk4-widget-factory), GTK3 (gtk3-widget-factory, mousepad, меню, диалог открытия файла), Qt6 (qterminal). Исправлено: Qt не видел монитор (не отправлялось `zxdg_output_v1.name` в версии 3); добавлен primary selection (вставка средней кнопкой). Осталось: Firefox, который в Ubuntu ставится только через snap, а в WSL1 snap нет. Нужен .deb из репозитория Mozilla, его подключение — на твоё решение.
2. Vulkan, дальше. Готово: кадр собирается на GPU, стекло рисуют шейдеры Liquify. Окна клиентов теперь сразу текстуры GPU: из shm заливается только то, что клиент пометил повреждённым. Рамка и тень окна — отдельная текстура на окно, CPU перерисовывает её только при смене заголовка, фокуса, наведения на кнопку или размера. Перетаскивание окна процессору ничего не стоит. Обои — одна текстура на монитор. CPU-слоёв осталось два (содержимое панели; оверлеи с курсором), они очищаются и заливаются только там, где у них есть содержимое. На lavapipe кадр сверен с CPU-путём: 97–98% пикселей совпадают точно, отличие только в матовости стекла. Ошибок слоя проверки нет, в том числе с окном на стыке двух мониторов с масштабом 1 и 1,25. Осталось:
   - импорт linux-dmabuf, чтобы браузеры и игры работали без копирования;
   - асинхронная отправка кадров вместо ожидания;
   - замер на настоящем AMD и на Celeron N4040.
3. DRM/KMS-бэкенд на собственных ioctl. Первая часть написана, но ещё не запускалась: в WSL нет DRM. Есть вывод на все подключённые мониторы (родной режим, page flip), ввод из evdev (клавиатура, мышь, тачпад), переключение VT. Мониторы, клавиатуры и мыши подключаются и отключаются на ходу (свой сокет uevent ядра, без libudev); если отключить все мониторы, рабочий стол ждёт следующего. Вход через logind (TakeDevice по D-Bus) пока не сделан: устройства ввода открываются напрямую, нужна группа `input`. Осталось: проверка на железе, atomic и планы, аппаратный курсор, VRR, кадр с GPU прямо в scanout без копии, настройки скорости указателя и тачпада.
4. XWayland (свой XWM) для Steam и игр. Готово: запуск по требованию, окна, меню, фокус, полный экран, буфер обмена в обе стороны. Проверено в WSL на xterm, xeyes, xclock, xclip. Перезапуск, если Xwayland упал. Нужен пакет `xwayland`; отключить — `RESC_XWAYLAND=0`. Программы, запущенные из рабочего стола, получают `DISPLAY`. Осталось:

## Обновления

Установленная система обновляется сама: «Параметры» → «О системе» → «Обновления» → «Проверить» → «Обновить» → «Перезапустить» (или `resc-desk update` в терминале и `resc-desk ctl restart`). Программа скачивается из последнего релиза https://github.com/Fitertom/resc-desk/releases и заменяет тот файл, из которого запущена, поэтому у пользователя должны быть права на запись в его папку (например, `~/.local/bin/resc-desk`, а не `/usr/bin`). Нужен `curl` (в Arch он есть всегда).

Выпустить релиз: закоммитить и запушить, затем в Git Bash на Windows `scripts/release.sh` — соберёт release-версию в Arch WSL, посчитает SHA-256 и выложит через `gh` с заметками из коммитов с прошлого релиза.
